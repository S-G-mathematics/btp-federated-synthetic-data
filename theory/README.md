# Theory index

The original theoretical framework is preserved in [LaTeX](BTP_Theoretical_Framework.tex) and [PDF](BTP_Theoretical_Framework.pdf). Use [notation](notation.md), [assumptions](assumptions.md), [statement map](statements.md) and [proof-to-experiment map](proof_to_experiment_map.csv) to locate claims. Some formal additions postdate experiment selection; they did not prospectively govern the original protocol. Finite-query bounds are not population-TV guarantees, and numerical identity checks are not proofs.
