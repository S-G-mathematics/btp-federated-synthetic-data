## 1. Scientific question, target and decision rule

The leading question is: **Under a fixed client-population target and explicit release budget, when can statistical aggregation improve synthetic-data fidelity over sample-size weighting, and when should it retain sample-size weighting?** The primary measured endpoint is the maximum absolute difference in registered bounded-query answers between a real reference dataset and a synthetic dataset. For each training split, the client target masses `alpha_i=n_i/sum_j n_j` are fixed. Aggregation weights `w_i` change generator contributions, not the definition of the target. Adult's `fnlwgt` remains a feature, not a survey weight.

The primary development reference is the **alpha-standardized empirical held-out client mixture**. The ordinary unweighted pooled held-out answer is saved separately. The provisional practical improvement threshold is an absolute primary query-max reduction of **0.005** relative to tuned projected size weighting. The fixed constrained comparator has `||w-alpha||_1<=0.25` and `w_i>=0.5 alpha_i`; subgroup and AUROC guardrails are assessed separately. These are registered application choices, not universal statistical constants. A negative paired difference favors the candidate.

The work is a non-neural, same-schema federated simulation. Each client fits a local joint model; the server combines permitted releases to generate synthetic rows. Real per-record likelihood evaluations for F1–F3 are **privileged evaluator access** and not a deployable model-only protocol. Unnoised released summaries and client models are **nonprivate**. The primary endpoint concerns finite real and generated datasets, not measured population total variation.

Six non-neural local families were implemented or exercised: independent mixed histograms; Chow-Liu smoothed dependency trees; Gaussian copula with empirical marginals; mixed Gaussian mixture with standardized numerics, optional heavy-tail transforms, component categorical probabilities and convergence checks; compressed prototype KDE; and exact-bin latent class. Independent, Chow-Liu and latent class use declared integer/bin probability mass including within-bin integer probability. Copula and rounded/clipped GMM scores remain **approximate**. Local tuning uses train/local-tune data, saved trial tables and checkpoints. Expanded GMM capacity materially improved one age/K5 assessment query max from about 0.099 to 0.056, motivating stronger size-weighted baselines.
