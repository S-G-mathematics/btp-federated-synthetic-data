# Dataset provenance

Official Adult source archive and originals, and UCI Bank Marketing `bank-additional-full.csv`, are included from the private research project where licensing permits. The preserved `data_manifest.json` files record exact source/member SHA-256 and row counts. Bank `duration` is excluded for the pre-call task. The test files are retained for provenance; reproduction routines must not fit on them. Verify with `python scripts/verify_data_sources.py`.
