# Saved evidence

Canonical small CSV/JSON result files were copied without numeric edits. The source-to-repository hash map identifies each copy. Historical unprojected, corrected development, external Bank, and frozen confirmation outputs remain in separate source directories. Large pickles, generated draws and some per-record files are represented in the full archive manifest and are not silently claimed to be in Git. `results/summaries/` is derived from saved author tables and the original closure register.
