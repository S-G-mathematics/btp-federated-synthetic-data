# Projected development secondary-gate protocol

**Fixed on:** 24 October 2026 UTC, after inspecting version 2 Exp 1/2 and constrained fidelity, before inspecting any secondary-gate results from the cells below. This is exploratory development evidence because the cell families were chosen after the primary campaign. It is not independent Adult confirmation.

## Fixed cells and comparison

Use Chow-Liu / age / K=5 and mixed GMM / label skew / K=10, each at development seeds101, 202 and 303. The former is a representative exact-score age cell; the latter is the harder skew with the only selected-rule slice clearing the primary fidelity margin, but its unconstrained selected weights violate the client-mass budget. Compare **size weighting** with the registered fixed query-minimax rule constrained by L1(w,alpha)≤0.25 and w_i≥0.5alpha_i. Use the existing version 2 local checkpoints and constrained weight fits. Do not include the unacceptable unconstrained rule as a viable utility candidate. Keep m=10,000 synthetic training rows and public generation seeds fixed across methods within each cell. Use separate 3,000-row synthetic tuning and 3,000-row synthetic probability-calibration draws. No real held-out record enters statistical-server fitting.

## Subgroup endpoint

For five independent 10,000-row synthetic subgroup draws per method and cell (the first also supplies predictive training), compare alpha-standardized real development-assessment prevalence with synthetic prevalence for the fixed bounded queries: sex Female/Male; race White/Black/Asian-Pac-Islander; education HS-grad/Bachelors/Masters; income >50K; age 17–30, 31–45, 46–60, 61–90; and the conjunctions Female×income-high, Male×income-high, Black×income-high and Bachelors×income-high. Preserve the whole query-answer table. Treat real reference mass at least 1% as supported for the binary guardrail; report rarer groups with their counts and uncertainty but do not silently omit them. The provisional subgroup noninferiority guardrail is at most +0.01 worsening in maximum supported-group absolute prevalence error versus size, averaged over the three split seeds. This is an application tolerance, not a significance test.

## Downstream utility endpoint

Train both logistic regression and an extra-trees learner on each method's projected synthetic training draw. Tune a small declared parameter grid using only an independent synthetic tuning draw and weighted Brier score. Fit a one-dimensional Platt calibration model from a separate synthetic calibration draw. Compare to a **privileged** real-trained same-learner TRTR reference, tuned on real local-tune rows and calibrated on real calibration rows; it is not a deployable server model. All predictors use the same 14 Adult features, including `fnlwgt` as a feature. Evaluate paired income probabilities on the **same** development-assessment people, with alpha-standardized client weights. Save row IDs, client IDs, labels and predicted probabilities. Report AUROC, AUPRC, Brier, log loss, fixed-bin ECE, balanced accuracy and F1 globally and by client. AUROC/AUPRC are undefined for a single-class client and must be marked unavailable, never imputed. The registered method-versus-size AUROC noninferiority tolerance is −0.01 on the three-seed mean for each learner; report the full per-seed range and worst-client values, without treating overlapping Adult splits as independent cohorts. Calibration and hyperparameter choice must never use development-assessment or official-test outcomes.

## Execution and access

Use the existing shared heavy-compute lease, one worker and one native thread, with the resource reserve and cell/campaign timeouts in `configs/resources.yaml`. Write outputs under a new `results/projected_secondary_20261024/` root with code/config/split hashes, selected settings, synthetic seeds and counts, model checkpoints, raw paired predictions, failures and wall times. Keep this secondary evaluator separate from the version 2 release-only weighting fit. It may read real rows only for TRTR reference fitting and final privileged assessment. The main synthetic releases and unnoised calibration summaries remain nonprivate. Do not open official Adult test or confirmation seeds404/505.
