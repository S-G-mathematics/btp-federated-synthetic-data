# Registered global Adult generator selection rule

**Registered 25 October 2026 before generating the missing validation draws.** This document fixes the rule; the resulting family and numbers belong in `docs/GLOBAL_SELECTION_DECISION.md`. The corrected projected v2 checkpoints are the only eligible source. No model is refit for this choice.

Candidates are `copula`, `chow_liu`, and `mixed_gmm`. Each has the same 18 partition (age, age+education, label skew) by K (5, 10) by seed (101, 202, 303) cells. All clients use the saved train/local-tune selected setting and saved projected checkpoint. All generators use exact size weights `alpha` from each cell's training counts, largest-remainder allocation and `m=10000`.

For each cell, score five independent validation draws using synthetic seeds `cell_seed+4200+r`, `r=0,1,2,3,4`. The existing `r=0` `size` validation result may be reused only after a regenerated first draw matches its saved primary loss to `1e-10`; the program checks this before proceeding. The reference is the alpha-standardized empirical **validation** client dataset, measured on the unchanged `projected_v2` primary query workload. Assessment, unseen audit and official-test results do not enter selection. A missing, invalid or unsupported cell fails the gate rather than disappearing from the denominator.

Average the five query-max losses within each cell, then average the 18 cell means equally by family. Select the smallest family mean. Families within **absolute 0.001** of the minimum are tied. Break that tie using the lower median total serialized client-checkpoint bytes over the same 18 cells; if still tied, the lower median sum of selected local-trial fit seconds; if still tied, lexical family name. Eligibility requires the existing hard schema validity and convergence checks. Approximate raw likelihoods are never compared across families.

This selects one global generator family only. It does not select a per-cell winner or change the registered Adult negative weighting finding. The weight rule for the main frozen procedure remains `w=alpha`. Utility and viewed assessment results will be reported as limitations and secondary outcomes, not undisclosed tie breakers. The family chosen here is also the first family for the prospectively specified external two-family screen; the second is the lowest mean validation-loss alternative.
