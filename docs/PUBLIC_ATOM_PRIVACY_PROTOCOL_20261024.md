# Public zero-atom histogram privacy protocol

**Fixed:** 24 October 2026 UTC after inspecting the prior public-bin histogram's structural-zero failure and before the corrected results. This is a separate, standalone baseline, not privacy for the projected client models or full research bundle.

Use the published Adult public schema, bins=8 per numeric column, with a declared zero atom for `capital-gain` and `capital-loss` and seven public positive integer bins across the fixed public support. For every generated record, apply the declared public education-to-education-number map as deterministic postprocessing. Matched nonprivate and private histograms use identical bins, categories, public map, integer samplers, fixed public client membership/sizes and independent-column model family. The nonprivate version adds a `1e-12` smoothing count. The private version adds fresh OS-entropy Laplace noise with scale `2d/epsilon`, d=15, to each count, clips positive and normalizes. Under fixed public client size and replacement adjacency, a single 15-column histogram release is epsilon-DP because the concatenated count vector has L1 sensitivity 2d=30. No noise seed is serialized. Public synthetic sampling seeds are postprocessing. This claim excludes data-dependent membership/size/assignment, the fitted projected models, unnoised summaries, privileged real scores, repeated settings and raw research files.
