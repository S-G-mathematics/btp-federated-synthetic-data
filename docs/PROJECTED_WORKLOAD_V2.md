# Postpilot projected-model workload v2

**Registered:** 24 October 2026 UTC, after inspecting the raw 54-cell development results and the education-code repair ablation. This workload is a future development protocol. It cannot serve as an independent audit of those earlier results.

The primary workload retains every historical query in its original order and adds one bounded query: the fraction of rows where `education` has no declared public code or `education-num` differs from its declared code. Thus `education='?'` and unsupported categories count as relation violations rather than being silently filled. The development unseen workload retains its original queries and adds the fixed conjunction `education=Bachelors AND education-num=13 AND income>50K`. The fixed mapping lives in `btp.privacy.PUBLIC_EDUCATION_NUMBER_MAP`; `btp.projected_workload.projected_workloads_v2` defines the query lists. Neither rule reads official-test data.

The new primary query is released as an **unnoised nonprivate** aggregate calibration summary in every projected version 2 cell. Use the same fixed alpha-standardized reference and size baseline. Each result root records workload version and serialized query list; the first-pilot audit records the map hash, and per-cell release contracts record the fixed map. The historical `btp.evaluation.public_workloads` and all 54 raw-model outputs remain version 1. The v2 unseen interaction is a development guardrail, not independent confirmation. The corrected deterministic version 2 matrix now covers 54 core cells across seeds101/202/303; see `docs/PROJECTED_MATRIX_FINDINGS_20261024.md`.
