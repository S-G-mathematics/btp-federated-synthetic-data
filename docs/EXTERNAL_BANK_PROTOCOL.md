# Registered external replication: official UCI Bank Marketing additional-full

**Registered 25 October 2026 before any external assessment scoring.** Source: [UCI Bank Marketing](https://archive.ics.uci.edu/dataset/222/bank%2Bmarketing), the nested `bank-additional/bank-additional-full.csv` member only (41,188 ordered rows, 20 input columns plus `y`). Archive and member SHA-256 values will be recorded after the official source is fetched and before fitting. License/attribution: UCI Bank Marketing, Moro, Cortez and Rita (2014), CC BY 4.0. Repeated contacts may belong to the same person; no person IDs are supplied, so record-level splitting does not establish person independence. The source order carries chronology, but this registered batch uses a random grouped split and makes no temporal deployment claim.

## Immutable task and split

`duration` is post-contact and is removed before fitting, workload design, schema estimation or evaluation. All retained `unknown` categories remain explicit. `pdays=999` is kept as a **categorical** no-prior-contact atom; no continuous smoothing or Genuity code enters this workflow. The integer columns age, campaign and previous remain integers; economic decimal measurements are reversibly scaled by 1000 to integers with a precision check. This common representation serves all compared generators. The original-resolution result can be obtained by division by the declared factor, with no category changes.

Stable source row IDs are `bank:000000` onward and are never predictors. Duplicate groups use all retained predictors plus `y` after duration removal, so rows differing only by the excluded post-contact duration stay together. Split seed **7171** allocates about 55% train, 15% local tune, 10% calibration, 10% selection validation and 10% untouched external assessment, stratified by `y` while retaining groups. The exact source, cleaning and split hashes/counts are frozen in `EXTERNAL_PROTOCOL_FROZEN.json` before assessment. Numeric support bounds use training minima/maxima expanded on each side by the ceiling of 10% of the observed range, at least one integer unit, with age/campaign/previous lower bounds at zero. Categorical vocab is from training only. This common training-derived schema is an unnoised metadata release. Assessment extrema/categories never revise it. Empty positive-mass reference clients yield unsupported cells, not repaired assignments.

## Fixed cells and access

The Adult validation-only rule selected **copula** (`G*`); the lowest-loss alternative is **Chow-Liu**. No external result can replace `G*`. Run these two families, soft age+education and label-skew assignments, K=5, seeds611/622/633, total **12 fitting cells**. Age+education uses training age quintile edges and documented education order; label skew uses training-fitted Dirichlet assignment. Severity is fixed at 0.8. Only label-skew routing includes five-percent common mass; age+education uses its declared softmax. The same training-fitted assignment rule is applied to every split. Label-driven assessment routing is only a privileged benchmark assignment; no deployable prediction router is claimed.

Per-client generator settings are chosen from the existing Adult six-candidate bins `{8,16,32}` by smoothing `{0.1,1.0}` grid using local train/local tune query MAE, 1,000 generated local-tune samples and finite-score/support checks. Copula likelihood is approximate; Chow-Liu likelihood is exact for its declared integerized model. No cross-family likelihood ranking is used. Fixed fit, tuning, assignment, pilot and draw substreams are deterministic and separately recorded. Model failures remain failures. No rebalancing from assessment labels.

Methods are size `w=alpha`, uniform and the **same fixed constrained query minimax** implementation as Adult, with `||w-alpha||_1<=0.25`, `w_i>=0.5alpha_i`. The constrained server receives only local model releases, declared train-derived schema/counts, an aggregate alpha-standardized calibration query vector and independent 5,000-row/client synthetic pilot query means. It receives no calibration person rows, per-person scores or assessment outcomes. The same pilot also supplies a fixed-pilot unconstrained LP diagnostic with its finite-matrix certificate. Both the main and challenger pipelines are **nonprivate**.

Queries use documented columns and training-only quantile thresholds. Primary: every retained categorical equality, every numeric 20/40/60/80 percentile threshold, and registered two-way label interactions for education, job, `pdays=999`, contact, previous campaign outcome and age-median. The separate audit contains fixed three-way combinations of age, education, job, previous contact and outcome, plus economic-state interactions. Query definitions and their hash are written before assessment reads. Query-max against the alpha-standardized empirical reference is primary; query MAE and ordinary pooled reference are secondary. Adult's absolute practical margin **0.005** transfers unchanged as an operational criterion; it need not have the same substantive meaning for every workload.

Each method/cell receives five independent m=10,000 **assessment** draws. Largest-remainder allocation makes exact row counts. Report paired per-cell and three-seed slice differences, target-mass L1, minimum client ratio, support, query/column/dependency diagnostics and one fixed logistic TSTR/TRTR proper-score comparator. The 60 synthetic draws per method (180 total) are repeated samples from 12 related fitting cells, not independent populations. All twelve cells get terminal statuses; at most two environment/adapter repairs per distinct failure, no result-driven parameter search. External outputs are read once under the frozen protocol and cannot modify the Adult selection or confirmation plan.

Evidence will reside under `data/external_bank/`, `reports/external_replication/`, `results/external_bank_20261025/`, `EXTERNAL_PROTOCOL_FROZEN.json` and the corresponding logs. Failures and incompatible schema/method cases remain in the status table. No chronological or person-level generalization claim is made.
