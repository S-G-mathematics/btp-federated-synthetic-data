EIGHT CANDIDATE STATISTICAL FAMILIES -- NOT EIGHT CLAIMED INVENTIONS
Evaluate every family below and keep its original interpretation:

F1. Predictive-score weighting: pseudo_bma_logscore; softmax common-reference log scores, stable normalization and temperature sensitivity.
F2. Bayesian weighting: predictive_evidence_bma in this repository is CONDITIONAL evidence over frozen fitted candidates with a declared model prior. Nonuniform reference row weights make it power/generalized predictive evidence. It is not integrated training-model evidence. If implementing classical BMA, specify actual common-target likelihood, priors and parameter integration. With uniform prior and temperature 1, F1/F2 may coincide; record that equivalence, do not count it as two distinct discoveries.
F3. Stacking: stacking_logscore maximizes the score of the combined predictive distribution; it differs from separately scoring each candidate.
F4. Moment calibration/entropy balancing: moment_l2, entropy_calibration, query_minimax and uncertainty_gls are variants/baselines, not four new families. Use real-data summaries only under the declared release protocol. GLS weights residual measurements using a defensible covariance, not different client population means as if they estimated one common truth.
F5. Kernel mean matching: kernel_mean_matching calibrates generator-level random-feature kernel mean embeddings. Public kernel feature mapping and target embedding are explicitly defined; label it an adaptation of observation-level KMM.
F6. Robust/minimax calibration: robust_query_calibration minimizes a declared uncertainty-adjusted worst query residual. It is not a faithful implementation of predictive Agnostic Federated Learning, and must not be named/reported as such. If trying predictive minimax later, keep its objective distinct from reconstructing a fixed D_R.
F7. Logarithmic pooling: normalized geometric pool. Current code is restricted to finite synthetic candidate support and learns coefficients from permitted summaries. Record support size, floor/smoothing, convergence and diversity ceiling. It is a different aggregation operator from a linear mixture.
F8. Transport/Wasserstein pooling: current code constructs a finite empirical ENTROPIC barycenter on synthetic candidates with a declared numeric/categorical transport cost; base weights and optional candidate search are explicit. It is not the exact unregularized continuous barycenter. Report support/projection/regularization errors and best-found search limits. Raw real rows must not become its candidate support.

Uniform and sample-size mixture weighting are mandatory additional baselines. Similarity-and-size weighting inspired by Fed-TGAN is a useful extra comparator only if correctly labeled an adaptation; the paper weights neural parameters, not independent client generators.
